# Ogland România — Calculator FiveM RP

Site static HTML/CSS/JavaScript. Calculatorul reține 30% comision și afișează 70% din suma introdusă.

## Publicare pe GitHub Pages
1. Creează un repository nou pe GitHub, de exemplu `ogland-calculator`.
2. Încarcă toate fișierele și folderul `assets` din acest proiect în rădăcina repository-ului.
3. Deschide **Settings → Pages**.
4. La **Build and deployment**, alege **Deploy from a branch**.
5. Selectează branch-ul `main` și folderul `/ (root)`, apoi apasă **Save**.
6. După publicare, GitHub îți va afișa adresa site-ului.

Nu necesită server, bază de date sau chei API.
